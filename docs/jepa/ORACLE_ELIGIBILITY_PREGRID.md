# Oracle raw visibility and population eligibility runner

Implementation only; no population eligibility outcomes have been generated by this work package. The orchestrator must first commit the reviewed waveform config and code, bind the independent review, and allocate CPU time in the cumulative ledger.

`masks.retained_oracle_transform` takes the raw 2048-coordinate covariance and a complete raw split, extracts the marginal in exact context-then-target order, checks retained joint SPD before Cholesky, and returns its inverse lower Cholesky with the coordinate-order manifest. Unused/gap covariance is never conditioned on or whitened. `oracle_preprocess` requires this exact index ordering and a lower-triangular transform with positive diagonal; it transforms retained measurements and embeds them at the original 8x256 positions with unused coordinates exactly zero. Context cannot depend on raw target/gap. Target innovations may depend on raw context.

Eight bounded synthetic tests in `tests/test_oracle_visibility.py` passed in 0.21 s (tool wall 0.527580 s). They cover the exact linear Jacobian, finite perturbations, all four original mask positions, unused zeros, index-order/shape/symmetric-transform rejection, and joint singularity. These fixtures do not assert any waveform split is theorem-eligible.

The unexecuted `check_waveform_population.py` runner reports all four declared splits for one explicitly specified approved `(line_multiplier, common_strength)` cell. It computes actual context/target/residual loadings, numerical ranks and singular-value ratios, the joint noise minimum eigenvalue, population gamma_n and oracle canonical margins. It retains rank-ineligible splits and does not choose replacement masks. Completion means all four records exist, not all four are eligible. If every split is oracle-ineligible, the orchestrator records scoped G6 rather than changing the masks.

Execution requires the full committed SHA, reviewed configuration SHA256, an accessible review report, a fresh return directory, a fresh host-local raw directory, and a ledger allocation between 1 and 600 seconds. One-thread BLAS variables are mandatory. The runner rejects uncommitted scientific inputs, writes partial STOP records on timeout/error, records complete source/environment hashes and raw matrix hashes, and never overwrites an earlier attempt. Host-local noise covariance and J0 inputs allow independent recomputation without treating rounded summaries as raw evidence. A new attempt after STOP requires explicit coordinator resolution under the runbook.

A single cell does not establish eligibility for the complete E1b sweep. The coordinator must explicitly project and allocate the complete set of required cells before grids; this runner does not silently expand its allocation or launch them. It does not perform sample experiments, train models, select M masks, or modify configs.

## Independent-review runner guard repairs

The runner now admits only the two A1 one-factor sweeps: any declared line multiplier with common strength .45, or line multiplier zero with any declared common strength. Cartesian-product combinations outside those sweeps are rejected before an attempt directory is created.

Every initial scientific source/config hash is recomputed in the finally block, on both completion and STOP. Missing or changed input, changed review content, or changed HEAD forces stopped/nonzero status and blocks acceptance while preserving the original error and partial rows. Runbook and A1 amendment hashes are included.

Eligible P5 rows additionally record the maximum population recovery angle between pulled-back context row functionals and Ncc^-1 Ac, with the registered 1e-6 rad limit. Exceeding it preserves the failed row and stops with G1. Rank/canonical-ineligible rows retain their statuses and a not-evaluable recovery check; they are not coerced into recovery claims.

Four bounded runner-guard tests passed in 0.17 s (tool wall 0.385976 s): approved/rejected sweep combinations, changed/missing sources, raw-coordinate subspace-angle behavior, and an injected infrastructure STOP that changes a fixture source and verifies finally-path rehashing. The injected attempt substitutes the waveform constructor and never instantiates a population. No actual population eligibility run was executed.
