## Physical covariance from source

`latent_monitor/tier1.py::Cell.event` initializes the multichannel generator at structure seed 11 by generating eight samples, then fixes that channel structure. `noise_module/multichannel/generator.py::generate_shared_private` samples one shared process and eight private processes, with weights `sqrt(rho)*gains` and `sqrt(1-rho)*private_strengths`. Therefore channel mixing covariance is `H=rho*g*g.T+(1-rho)*diag(p**2)`. No realization normalization is enabled. The existing `NoiseModel.implied` divides its channel covariance by mean diagonal; that convenience representation must **not** be treated as the actual covariance while leaving its temporal PSD unchanged. JEPA reconstructs H from recorded source gains/private strengths and retains its absolute scale.

`NoiseGenerator.build_psd_density` normalizes the sum of reference components to total variance 1 with the finite-grid integration `sum(S)*fs/N`. DC is zero. Interior unnormalized rFFT powers are `P_k=S_k fs N/2`; DC and Nyquist use `P_k=S_k fs N`. Consequently temporal covariance lag is `irfft(P)/N`, the real circulant eigenvalues are `P/N`, and physical raw covariance is `H kron T`. A real white vector filtered by `sqrt(P/N)` in rFFT space has exactly this covariance. Source-generated components are Gaussian, so equivalent covariance synthesis gives the same law, though it intentionally uses separate recorded namespaces rather than the imported generator's event-ID RNG.

Reference component metadata exposes `integrated_power_after_global_scaling`. For the floor component this equals `v_floor=sum(S_floor)*fs/N`. The scalar reference white variance used by A1 is `v_white=mean(diag(H))*v_floor`. White component power is distributed uniformly over the non-DC one-sided density bins, including Nyquist, exactly like the source's reference white spectrum; it is not an independent sample-white law with zero Nyquist adjustment. Additional physical sample-white noise is separate: `epsilon=.01 mean(diag(H))*mean(diag(T))`, fixed from the reference once and held unchanged across every cell and SNR. Each cell includes fresh draws with this same epsilon. No whitening floor is interpreted as physical variance.

The wrapper exposes independent base-white shared/private, base-colored shared/private, physical epsilon-private, line and common components, whose sum is the actual generated noise. Splitting base white from colored uses the metadata-defined reference floor and preserves the original total Gaussian covariance. This component record supports later fault implementation; it does not itself resolve ambiguous fault combinations beyond the registered E4 definitions.

## Approved added components and deterministic basis

At the noiseless reference theta0, choose the non-DC rFFT bin with maximum spectral power; exact ties use the lower bin. Identical channel gains and phases mean line covariance is `ones(8,8) kron v_line*(cos cos.T+sin sin.T)`, with independent Gaussian I/Q coefficient variance `v_line=line_multiplier*v_white`.

The reference temporal covariance is real circulant. Interior Fourier modes have an exactly degenerate cosine/sine pair; DC and Nyquist have one real direction. Group equal analytic eigenvalues `P_k/N` exactly (not approximate numerical eigensolver values), in descending order. Within each group, construct its orthogonal projector from normalized real Fourier columns, project coordinate axes in ascending index, and apply twice-reorthogonalized Gram–Schmidt. Orient each vector so its first maximum-magnitude coordinate is positive. Multiply by sqrt(N) for mean square one. Select the first two vectors; record eigenvalues, multiplicities and second-to-third gap. This implements A1's projected-coordinate tie rule without allowing an eigensolver to arbitrarily rotate a sinusoidal pair. A small eigengap remains disclosed; it is not repaired by reselection.

Common covariance is `ones(8,8) kron (g*v_white/2)*(V.T V)`. Its coefficient variances are each `g*v_white/2`. All component draws are independent of physics and each other. A1 fixes g=.45 for E1b line sweep and E2, and line multiplier=0 for the E1b common sweep. Zero added line does not imply zero cross-noise. Neither component rescales the reference base or epsilon.
