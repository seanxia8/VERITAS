## Findings

### 1. [P1] P5 can destroy the target signal and lose the claimed context subspace

**Premise:** `docs/jepa/RUNBOOK_JEPA_NOISE_2026-10-16.md:200–205`: “the JEPA span maps back to R_c” after context-first joint noise whitening.

Let the full noise covariance have blocks `Ncc=I_2`, `Ntt=I_2`, `Ntc=diag(0.5,0)`; let `Ac=(1,0)^T`, `At=(0.5,0)^T`, and `Var(theta)=1`. Both original signal loadings have rank one and the full noise covariance is strictly positive definite (eigenvalues 0.5, 1, 1, 1.5). Lower-Cholesky whitening gives context signal `(1,0)` but **zero target signal**, because its innovations loading is `At-Ntc Ncc^-1 Ac=0`. Cross-view event covariance is zero after whitening. All canonical correlations vanish; the top context direction is arbitrary, and may be orthogonal to `R_c`.

This counterexample can be generated by a shared nuisance plus independent residual noises with positive variances. It does not require a singular noise covariance or target leakage.

**Consequence:** P5's universal statement, unit test at lines 377 and population-test requirement at 343–344 are false as written. Triangular whitening removes cross-view noise but can also remove shared physics. The illustrative population table at 208–213 cannot establish the missing condition.

**Correction:** require full rank of the **residualized target** signal loading, not merely the original target loading. For two views the condition is `rank(At-Ntc Ncc^-1 Ac)=k`; with an intervening gap use the corresponding innovations loading after conditioning on all preceding noise coordinates. State positive-definiteness and full-rank context assumptions. Check this condition and a conditioning margin in every oracle cell. Label rank-deficient cells ineligible for the recovery theorem. Derive the post-transform physics correlations; they need not equal the original no-sharing values.

### 2. [P1] The finite-beta prediction objective does not inherit P4's exact recovery guarantee

**Premise:** runbook `192–199` proves a noise-only GEVP, but `358–360` implements “prediction + SIGReg + β·tr(WΣ_recWᵀ)” and `240` requires the GD solution at beta=10 to recover the same subspace in every cell. Summary `37–38` calls the penalty's fixed point exactly `R_c`.

P4 is correct for its stated constrained **noise-only** objective. Adding a prediction term changes the minimizer. A concrete two-axis case has `Scc=Stt=I`, `Sct=diag(.001,.9)`, context signal covariance `diag(.01,0)` and noise covariance `diag(.99,1)`. It is realizable with independent physics on axis 1 and shared nuisance on axis 2. Under hard isotropy, for a one-dimensional representation the optimized prediction-plus-noise objective is `1-rho_i^2 + beta*Ncc[i,i]`. At beta=10 it is **10.899999** for the physics direction and **10.19** for the nuisance direction. The pure GEVP chooses physics; the combined objective does not.

**Consequence:** beta=10 is an empirical hypothesis, not a theorem or universal remedy. Soft SIGReg and the normalized deep overlay penalty in `502–504` are additional departures from the hard constraint, not proofs of equivalence. The toy `33–36` solves the pure GEVP and tests neither combined GD nor the deep objective.

**Correction:** scope P4 to its exact optimization problem. Treat finite-beta and deep recovery as registered empirical hypotheses; derive a beta bound involving the spectral gap if a guaranteed approximation is needed. Specify which encoder receives the linear penalty and which embeddings are constrained. Retain `anchor_only` and report failures without treating them as implementation defects.

### 3. [P1] The deep time mask does not implement the registered sample gap

**Premise:** runbook `413–414` requires context `[0,112)` and target `[144,256)`; `460–463` instead uses 32-sample patches, context patches 0–3 and target 4–7, “masking out of the loss the patch straddling the gap.”

There are **two** intersecting patches: patch 3 is `[96,128)` and patch 4 is `[128,160)`, each containing 16 gap samples. Removing a target loss term does not remove patch 3's gap values from context attention. The source backbone patch embed consumes the entire patch before temporal attention (`src/reconstruction_model/model.py:251–257`).

**Consequence:** the purported time-with-gap arm can use samples forbidden by its E1b split, changing noise coherence and signal availability. The existing “masked sample” gradient test at `471–472` can pass if gap samples are never designated masked. The oracle's covariance order at `510–511` also becomes inconsistent with actual visible input.

**Correction:** freeze exact sample visibility and target-loss support. Either align boundaries to patches and update all population calculations, or zero/replace forbidden samples before embedding with explicit partial-patch handling. Test zero gradient for every target **and gap** sample, including boundary patches; test an exact expected index list. Do not silently choose a new split after registration.

### 4. [P1] Criterion M cannot be selected using noise-only records as instructed

**Premise:** runbook `214–219` requires the kth **event** canonical correlation after subtracting noise cross-covariance, but `499–501` says to compute criterion M “once from noise-only records.”

Noise-only observations identify noise covariance, not `Ac Sigma_theta At^T`, nor its kth signal correlation. Two event populations can have identical noise records and opposite optimal masks. The criterion also leaves unspecified whether marginal covariances in its signal CCA are event marginals or noise-subtracted signal marginals; these define different statistics. With noiseless full-rank shared factors, signal-only CCA correlations can all equal one and conceal mask-dependent signal SNR.

**Consequence:** implementers must invent a data source and estimand, and could use probe/test events for mask selection. The E3 provision of 200 noise windows (`605`) also does not by itself satisfy M's `n>=20d` requirement for high-dimensional flattened views.

**Correction:** define M algebraically, including all marginal matrices, dimension reduction, regularization, rank handling, and tie breaking. Assign a disjoint calibration-event split and calibration-noise split before training, or explicitly label the synthetic selector oracle-based. State the corresponding real-data estimator and effective independent sample requirement. Preserve probe-test isolation.

### 5. [P1] E1b has no defined fixed rank-k linear signal subspace

**Premise:** runbook `155–157`, `189–191` define `R_c=span(Sigma_n,c^-1 Ac)` for a fixed linear loading; `410–430` carries the same methods, references and R1/R4 tests into the Tier-1 waveform family, while `428–429` specifies only the noise covariance.

`src/latent_monitor/tier1.py:95–118` draws amplitude, onset and decay time, then passes onset and decay into the nonlinear pulse template. Three scalar parameters do **not** imply a rank-three waveform covariance or a single fixed matrix `Ac`. A Jacobian tangent space depends on the event; a global covariance eigenspace is a different reference. The exact noise covariance alone specifies neither. The reference noise also includes rolloff and flicker (`200–207`), so setting the added line knob to zero does not automatically produce independent time-view residuals.

**Consequence:** R1/R4's E1b angle and the “no sharing” baseline are not currently reproducible quantities, and P3 cannot simply justify them.

**Correction:** choose and register either a genuinely linearized fixed-template E1b model, a declared population signal-covariance reference with a fixed rank rule, or event-dependent tangent-space diagnostics. State that the latter two are extensions outside P3. Verify actual cross-noise covariance at the baseline; report nonzero residual sharing instead of labeling it B_t=0.

### 6. [P1] E3 lacks a disjoint calibration, model-training and probe evaluation partition

**Premise:** runbook `591–595`, `597–638` selects four train, four val and sixteen science files, estimates coherence/selects masks/marks lines, trains five arms, and reports amplitude probes and sensitivities. It does not assign source files or windows to these roles. Generic ridge-probe isolation at `114–118` requires such a partition but does not instantiate it for E3.

The E2 synthetic integer ranges (`535–540`) do not define real-file splits. Adjacent or overlapping windows from one acquisition can share both samples and stable nuisance structure. Model/mask/line selection on the eventual evaluation windows would make the reported R9 outcome partly selected on those data.

**Consequence:** E3 is not ready for a reproducible held-out claim; this is an omission in the protocol, not a finding that leakage has already occurred.

**Correction:** freeze a manifest of file hashes, acquisition grouping and window intervals before feature inspection. Allocate disjoint calibration, SSL-train, probe-train and final-test acquisitions/windows; define buffers for temporal dependence. Fit normalization, line labels, mask selection and any sensitivity-band selection on declared calibration data; evaluate the locked R9 definition on held-out data. Specify amplitude-target extraction and verify target variance. Check stationarity of calibration noise versus event noise; otherwise P4's covariance premise does not hold.

### 7. [P1] The development cell is simultaneously excluded and required for R6

**Premise:** runbook `242` defines R6 over “3 levels × seeds” at nominal SNR, whereas `533–534` declares `(mid, nominal)` development-only and “never pooled.” That same cell chooses beta and lambda_J (`503–506`).

**Consequence:** R6 cannot use all three nominal levels while honoring the exclusion. Omitting the middle level changes its registered statistic; including its tuned runs contaminates the confirmatory aggregate. Selection criteria and tie rules for beta/lambda_J are also absent.

**Correction:** allocate separate development seeds and event IDs with an explicit independent confirmatory mid-level cohort, or change the registered R6 estimand before registration. Freeze selection metric, tie rule and selected checkpoint policy. State how seed pairing enters Spearman rather than leaving “levels × seeds” to interpretation.

### 8. [P2] The cited stop-gradient dynamics do not establish the proposed recovery and learning-order tests

**Premise:** runbook `170`, `353–355`, `379`, `432–436` invokes Littwin et al., ties the encoder across views, and requires recovery of `R_c` at gamma=0 for independently generated `Ac` and `At`.

The cited primary paper defines square shared encoders and diagonal covariance assumptions in §2 and derives learning effects in terms of regression coefficients, not an unrestricted CCA theorem. The current random-loading, colored-noise model generally lacks a common diagonal basis; the hard-whitened two-encoder CCA objective at `166–168` is a different problem. [Littwin et al., §2](https://arxiv.org/html/2407.03475v1#S2).

**Consequence:** failure of the stop-gradient recovery unit test need not indicate a bug. “Projection norm” on nonorthogonal signal/nuisance loadings can include other factors, and a step-to-50%-of-final metric can look early for an almost unlearned mode. The final step count, convergence rule and non-reaching convention are not frozen.

**Correction:** separate an assumption-matched reproduction from the detector generalization; derive or empirically qualify the latter. Define mode attribution, learning-rate/init normalization across depth, horizon, convergence tolerance, non-learning threshold and censored times. Treat R5 as a hypothesis rather than a consequence of the cited result.

### 9. [P2] Prediction pass rules are weak descriptive criteria, not inferential evidence

**Premise:** runbook `241`, `244–245` uses four of five or two of three paired seeds; `111–113` asks for mean ± standard deviation. It provides no uncertainty rule for the effect contrasts.

Under independent symmetric paired signs, at least two wins out of three has null probability **0.5**, and at least four out of five has probability **0.1875**. These are valid descriptive thresholds but cannot by themselves support confident directional conclusions. R9's amplitude condition `anchored R² >= .9*plain R²` also behaves poorly when the plain score is zero or negative: two unusable amplitude probes can satisfy the condition.

**Correction:** explicitly label current rules descriptive pilot success checks; report paired effect sizes and uncertainty using the actual independent sampling unit. If confirmatory claims are desired, freeze a power/precision target, seed count and multiplicity policy before outcomes. Add an absolute held-out amplitude performance requirement (and an explicit nonpositive-baseline convention) to the scientific interpretation of R9.

## Proposition-level conclusions

- **P1:** the cross-covariance expression is valid with zero-mean or centered variables and mutually uncorrelated physics/nuisance/residual components. These assumptions should be explicit. Canonical directions generally mix latent factors; separate ranking of named factors needs a separable-mode condition. Strong shared nuisance *can* displace weak physics, not universally for every loading geometry.
- **P2:** invertible per-view CCA invariance is valid when directions are mapped back. It does not establish invariance of arbitrary nonlinear networks, regularized/soft-constrained objectives or any loss called chi-square. The joint-whitening extension needs Finding 1's rank condition. The spectral formula needs the equal per-view power assumptions, which E3 at least asks to check.
- **P3:** valid for population CCA under positive-definite view/noise covariances, full-column-rank `Ac`, positive-definite `Sigma_theta`, full-rank target signal and zero cross-noise covariance. It concerns global optimum/context canonical subspace, not every fixed point of GD. “Fixed point” in the summary should be narrowed accordingly.
- **P4:** valid for the stated noise-only constrained GEVP, stationary matched noise, and retained signal rank. It does not prove the finite-beta/deep claims (Finding 2). An overlay identity additionally assumes independent zero-mean noise and a linear encoder.
- **P5:** false as stated (Finding 1).

SIGReg is a distributional regularizer, not exactly the hard covariance constraint used by the CCA proof. LeJEPA's description itself distinguishes the regularizer and predictive loss; this study should call its hard-constrained linear model an idealized analogue. [LeJEPA primary paper](https://arxiv.org/abs/2511.08544).
